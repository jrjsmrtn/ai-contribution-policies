# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.

The full text is at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>.

## Reporting

Report unacceptable behaviour to the maintainer: **<jrjsmrtn@gmail.com>**. Reports are handled
confidentially.

## A note specific to this project

This repository documents what organisations say about AI-authored contributions, including
positions its maintainer disagrees with, and including bans. **Recording a policy accurately is not
endorsing it, and criticising a policy is not a reason to record it inaccurately.** Disagreement
with a project's stance belongs in that project's own venue, not in a record about it.

Contributions arguing that a documented policy is wrong will be closed. Contributions showing that a
record *misstates* a policy are the most valuable thing here — see
[CONTRIBUTING.md](CONTRIBUTING.md).
